# NUMBER×RUSH Vol.55｜先頭24区間ローカルベンチマーク実測
日付: 2026-10-23

## 測定条件
- GitHubの `tools/verify-vol41.cpp` と同一ソースをローカルに保存してコンパイル。
- Linuxコンテナ、`g++ -O3 -std=c++17 -Wall -Wextra`、Nodeとは独立のC++実行。
- 各区間 `i=0..23` を別プロセスで実行。盤面 `[243*i,243*(i+1))`、キュー `[0,46656)`。
- Python `time.perf_counter` でプロセス起動から終了までの経過時間を測定。RSSは`/usr/bin/time -f peak_rss_kb=%M`。
- コンパイル実測 0.52秒、コンパイル最大RSS 70,952 KiB。
- 実行は8区間ずつ3群に分けて測定した。ジョブ起動・コンパイル・成果物アップロードを含むGitHub Actions時間ではない。

## 実測結果
- 24区間すべて正常終了。
- 各区間243盤面、46,656キュー。24区間で5,832盤面。
- 合計経過時間 **74.140秒**、平均 **3.089秒/区間**、中央値 **3.051秒/区間**。
- 最短 **2.726秒**、最長 **3.8726秒**。
- 最大RSS **123,264 KiB**（約120.375 MiB）。
- 延べ盤面×キュー組 **272,097,792**。
- 延べTARGET状態 **4,089,585,024**、延べTARGET一致ルート **17,142,160,896**。
- NEXT FREE候補なしの状態（FREE zero） **0件**、24区間すべて0。
- 全192区間に単純比例した場合、計算本体の合計CPU経過時間は約**593.12秒（9.89分）**。これは**予測であって実測ではない**。8ジョブ並列の壁時計時間やGitHub請求時間は別。
