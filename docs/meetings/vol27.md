# Vol.27｜ODD・EVEN追加とG4固定点の再検証（Ver.0.26暫定案）
日付: 2026-10-23
状態: **すべて暫定案・未正式承認**。実ゲーム全体のG4保証は未証明。

## ユーザー選択
- FREE・PAIR・TRIPLEにODD・EVENを追加。
- Variety Engineは難易度別の適正解法数帯を検討。
- 1→2→3の周期キューを検証専用モデルとして維持。
- 同種MISSION連続回避はソフト制約、Safety Engine / Variety Engineは分離。

## 検証モデル
6位置の通常タイル各値1,2,3、729盤面×キュー位相3。TARGET 1..18。MISSION FREE / PAIR / TRIPLE / ODD / EVEN。ODDは元数字が奇数のタイルを1枚以上、EVENは偶数のタイルを1枚以上選ぶ。全63非空部分集合をタイルIDで区別し、TARGET一致の全ルートを遷移として許可（MISSION未達のTARGET CLEARも含む）。消費した位置に昇順で周期キューを補充。NEXT MISSION/TARGETは回答前に選ぶ。REFRESHと特殊タイルは未対象。

## 実計算結果
- 現在FREE成立状態: **25,656**
- PAIR: **8,595**
- TRIPLE: **9,495**
- ODD: **24,600**
- EVEN: **20,919**
- MISSION区別の解答可能状態の総数 **89,265**。
- 全25,656の解答可能な盤面・位相・現在TARGETに対して、全現在TARGET一致ルートの遷移先で共通して成立するNEXT TARGETをMISSION別に検査:
  - FREE: 候補ゼロ0、候補数6〜15。
  - PAIR: 候補ゼロ0、候補数1〜5。
  - TRIPLE: 候補ゼロ0、候補数1〜6。
  - ODD: 候補ゼロ**13**、残り25,643では候補数4〜14。
  - EVEN: 候補ゼロ**1,424**、残り24,232では候補数5〜13。
- 最大安全固定点計算: 初期K=89,265状態。各Sについて、生成側がNEXT MISSION/TARGETを選び、プレイヤーの**すべてのTARGET一致ルート**の後でKに戻るかを検査。初回除外0で固定点。Kの全状態についてG4成立（限定モデル）。
- **重要:** G4成立は「NEXT MISSIONを生成側が選べる」ため。ODD・EVENを任意の状態から必ず出せるという意味ではない。安全性に反するMISSIONの強制は不可。

## 反例
- ODD: board=[1,2,2,2,2,2]、次補充値2（位相1）、TARGET1。唯一の1を消費して全て2になり、ODDを達成不能。
- EVEN: board=[1,1,1,1,1,1]、次補充値1（位相0）、TARGET1。どの1を消費しても盤面は全て1のまま、EVENを達成不能。
- これらはG2のMISSION固定時の反例であり、生成側がFREE/PAIR/TRIPLEを選べばG4を維持できる。

## Variety Engine提案（未承認）
MISSION CLEARの解法数について初期適正帯（**実測最適化前の仮値**）:
- EASY 3〜8通り
- NORMAL 2〜5通り
- HARD 1〜3通り
適正帯から外れる場合も安全候補から排除せず、評価点を下げるソフト制約を推奨。MISSION別補正とプレイテストで要調整。全TARGET一致ルート数とMISSION CLEARルート数は別に測定する。

## 検証の再現方法
6タイル全3^6盤面、位相3、各63部分集合のTARGETとMISSION成立を記録。各(盤面,位相,TARGET)で全TARGET一致ルート後の盤面を生成し、MISSION別の可能TARGET集合をビット集合で求め共通部分を計算。Kに属する状態について、あるNEXT MISSION/TARGETがすべての遷移先をKに入れるか確認し、変化がなくなるまで削り込む。
